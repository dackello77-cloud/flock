Turn on location for this page
  1. In Safari, tap the page icon left of the address → Website Settings → Location → Allow.

  3. Settings → Apps → Safari → Location → Ask or Allow.
  4. Still blocked? Settings → Screen Time → Content & Privacy Restrictions → Location Services → Allow Changes.
  5. If the page opened inside another app (WhatsApp, Instagram…), open it in Safari.
